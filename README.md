# 🍳 Mi Cocina – Frontend

## 📌 Descripción

Mi Cocina es una aplicación web de recetas desarrollada con React. Permite explorar diferentes recetas, consultar sus detalles y guardar preparaciones en una sección de favoritos.

Este repositorio contiene el desarrollo de la interfaz de usuario y su conexión con el backend mediante una API REST.

## 🛠️ Tecnologías utilizadas

- React
- Vite
- JavaScript
- React Router DOM
- Zustand
- React Hook Form
- CSS Modules

## ✨ Funcionalidades

- Visualización de recetas.
- Listado de recetas disponibles.
- Consulta del detalle de cada receta.
- Agregar y eliminar recetas favoritas.
- Navegación entre páginas.
- Formularios con validaciones.
- Diseño adaptable a diferentes dispositivos.

## ⚙️ Instalación

Clonar el repositorio:

```bash
git clone https://github.com/alvaroaznar703-md/mi-cocina-frontend.git
```

Ingresar a la carpeta:

```bash
cd mi-cocina-frontend
```

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en la dirección local que indique Vite, normalmente:

```text
http://localhost:5173
```

## 🔗 Conexión con el backend

El frontend consume los datos proporcionados por la API REST desarrollada con Node.js, Express y MySQL.

Para utilizar todas las funcionalidades es necesario tener el backend en funcionamiento.
